# PGON Wallet: прототип нового сайта

- `index.html` — лендинг под релокантов «Получай в рублях, трать в любой валюте» (реклама в FB/Instagram)
- `general.html` — общий вариант «Один баланс, две страны»
- `docs/` — юридические документы, перенесённые с pgonpay.ru/docs
- `assets/` — логотип, экраны приложения, фото оплаты по QR

Статичный HTML без сборки: открывается в любом браузере, шрифты Unbounded и Onest из Google Fonts.

Перед запуском проверить: курс в калькуляторе (сейчас пример 82,4 ₽), валюту баланса, условия реферальной программы, убрать пометку «прототип дизайна» в подвале.
